why it exists

Four concerns, one runtime

A modern agent runs untrusted plans, calls external APIs, and holds credentials — exactly the threat model you don't want on a shared cluster. smol-agents fuses the four hard problems into one coherent runtime so platform teams don't reinvent them per tenant.

🛡️

Isolation

Without: container namespaces (shared kernel) With: Kata + Firecracker microVM per agent (gVisor fallback)
🪪

Identity

Secrets

Per-agent microVM sandbox

Kata + Firecracker hardware isolation per agent, with a gVisor fallback when no KVM exists and runc for dev. Two-layer containment: host eBPF visibility and the microVM.

isolation

Fail-closed run datapath

AgentRun pods pin a sandbox RuntimeClass — a run holds Pending rather than execute unisolated. Danger flags (--dangerously-skip-permissions) are microVM-gated and opt-in only.

isolation

Isolation-aware node provisioning

AgentNodePool derives KVM/metal node shape from an agent's sandbox and compiles to a Karpenter NodePool + EC2NodeClass — exactly the nodes the isolation needs.

isolation

Zero-trust SPIFFE identity

Per-agent X.509 + JWT SVIDs, auto-rotated, issued by SPIRE over the CSI driver. Three modes: insecure / permissive / strict.

identity

Dual-rail mTLS transport

SPIFFE mTLS on both rails: a public gateway and a private mesh. In strict mode every connection is identity-checked.

identity

Secret broker (UDS lease)

A kloak-style broker mints credentials per request over a Unix socket, authenticated by SO_PEERCRED + SPIFFE. The agent process never reads a provider key.

secrets

Secretless egress (TraT)

The agent's GitHub/GitLab token is minted, injected at the proxy seam, and exfil-blocked without the agent ever touching it — authorized by a Transaction Token (TraT).

secrets

Dynamic credential policy

DynamicCredentialBackend defines operator-granted, dynamically-minted provider credentials — short-lived, TraT-authorized, never persisted.

secrets

eBPF egress cage

Host CO-RE eBPF transparently redirects outbound calls to the agentnet sidecar and drops anything off the allow-list at the egress hook. The agent can't disable it.

network

Identity-aware egress proxy

AgentNetwork wires an identity proxy / WireGuard mesh plus a default-deny egress NetworkPolicy floor (DNS + in-cluster + public 80/443; cloud-metadata & link-local blocked).

network

Plan–act–observe loop

The core executor runs a bounded plan→act→observe loop with a replayable step log, behind an explicit TurnExecutor.Execute(Turn)→Result seam.

runtime

Hard budgets, formally proven

Each agent carries a hard budget — maxSteps / maxTokens / maxWallClock / maxToolCalls — that the Quint model proves is never exceeded.

runtime

MCP-typed tools

Tool declares input/output JSON Schema; malformed tool calls are rejected before dispatch. Kinds: mcp, http, agent, fanout, task, teammate, teambus.

runtime

Fanout (map-reduce)

kind=fanout is a Send-style runtime map-reduce tool: spawn N child invocations with a width limiter, then fold their results.

runtime

Replayable runs

AgentRun is a single invocation with states aligned to the OpenAI Assistants API and a replayable step log folded into status.

runtime

Durable sessions

AgentSession runs a long-lived serve-session worker that checkpoints its turn log to AgentFS and resumes on restart, parking in RequiresAction when idle.

runtime

Gateway + queue + autoscaling

A stateless agentgateway (Knative Service, scale-to-zero) publishes turns to NATS JetStream; session workers consume them durably with per-tenant concurrency caps.

runtime

Run governance & quotas

AgentRunQuota + an admission queue enforce per-tenant concurrency caps for mid-scale (~100s concurrent) operation.

runtime

Agent-to-agent composition

kind=agent tools spawn child runs with field-wise usage roll-up and ownerRef subtree garbage collection — agents compose into agents.

orchestration

Agent teams

AgentTeam: a shared task list (NATS KV CAS), per-member peer mailbox with provable NATS-ACL isolation, team budget roll-up, and subtree GC.

orchestration

Generator–verifier coordination

Coordination controllers run a generator-verifier loop with a BudgetGuard, WidthLimiter, ThreeWayMerge, and M5-reuse approval hooks.

orchestration

Declarative workflows (DAG)

AgentWorkflow is a result-routed DAG (StateGraph) CRD with operator-side CEL predicate evaluation for conditional routing.

orchestration

Agent memory as an MCP service

Vector / graph / KV / event-log / filesystem backends behind one MCP gateway, with tenant isolation, deny-by-default policy, quotas, and audit.

memory

Branchable filesystem memory

Branchable, 3-way-mergeable filesystem memory backed by Turso AgentFS — with cross-pod file-state recovery proven live.

memory

Kopia versioning backend

A pluggable kopia backend gives AgentFS content-addressed snapshots with automatic periodic snapshots (S3/minio backup, or ephemeral in-pod repo).

memory

Retrieval pipelines

MemoryRetriever defines an embedding → chunking → topK → quota pipeline over stores, deny-by-default.

memory

Episodic memory & recall

pkg/agentepisode records run episodes and does pre-run few-shot recall — agents learn from their own history.

memory

Human-attachable agents

Driver-mode terminal attach: a human authenticates against a bundled OIDC IdP, an AttachGrant authorizes, and agentterminal reverse-proxies a recorded ttyd/tmux PTY (viewer read-only, driver writable).

human-in-loop

Human-in-the-loop approval

An M5 pre-run approval gate pauses a run for human plan approval (approve / reject / cancel) before execution — reused by team coordination.

human-in-loop

Audience-bound attach tokens

pkg/attachtoken resolves an AttachGrant into an audience-bound, short-TTL token before a WSS terminal session — human identity on the SPIFFE-machine rail.

human-in-loop

Live step stream + OTel spans

A live per-step turn event stream with OpenTelemetry step spans — watch a run plan, act, and observe in real time.

observability

Honest cost accounting

Cost is integer milli-USD, observability-only — never a gate. Usage rolls up field-wise across child runs (never a blind add); tool-calls are never gated on.

observability

Calibrated LLM-judge verifier

pkg/agentjudge is a calibrated LLM-as-judge primitive, usable as an in-loop verifier middleware (after-model hook) or a standalone scorer.

observability

How one egress request stays safe

The agent makes a plain outbound call. It never holds the credential and cannot reach an unlisted host — by construction.

The agent makes an ordinary outbound request — no SDK, no key.

Stamp identity

The sidecar originates upstream TLS and stamps a fresh JWT-SVID / TraT.

Mint credential

For provider APIs, the broker injects a short-lived, agent-blind credential.

Drop the rest
